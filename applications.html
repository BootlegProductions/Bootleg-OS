Applications // experiments // useful things

Tools built by learning the hard way.

I learned web, interface and graphic design while pushing through university during the disruption of COVID. The work here mixes practical browser tools with the design skills I picked up along the way — including an award-winning graphic design poster project.

The applications are a place to keep learning in public: HTML, CSS, JavaScript, APIs, UI/UX, image editing, graphic design and interactive media all live together instead of being reduced to screenshots.
