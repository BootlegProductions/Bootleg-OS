What is Bootleg OS?

The story behind turning an old university portfolio into a growing personal creative hub.

In this post Bootleg OS is both an archive of past work and a place where the applications can keep changing.

A portfolio that became a place to build

Bootleg OS started with the remains of an older university portfolio. The aim was originally straightforward: recover the useful parts, modernise the presentation and create somewhere to show web design, graphics and project work.

It quickly became more interesting once practical applications started returning to the site. The portfolio now behaves more like a small personal operating system: folders open projects and galleries, the header contains a working radio, and individual applications handle weather, time, archive links and other utilities.

Why keep the tools?

A screenshot can show that an interface existed. A working application shows what it actually does. Keeping the utilities live means the portfolio can demonstrate JavaScript, APIs, interface design and experimentation rather than only presenting finished images.

Where it goes next

The current structure is designed to expand. New projects get their own pages, blog posts live in a reusable folder structure, and applications remain separate tools rather than being compressed into one oversized dashboard.
