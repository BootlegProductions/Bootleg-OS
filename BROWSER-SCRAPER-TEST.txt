Browser-only Archive Scraper experiment. Open archive-scraper.html with Live Server or GitHub Pages. Paste a public Internet Archive item URL first. If the browser reports a CORS/network error, the Internet Archive endpoint does not permit direct browser access in that environment. Original Python scraper remains in tools/archive-link-scraper/. Bulk searches limited to first 100 items. No external hosting or payment required. ZIP contains TXT lists only. Live Internet Archive requests could not be verified in this offline build environment.
