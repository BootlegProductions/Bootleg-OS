PIP-BOY BUILD PROCESS IMAGE ARCHIVE
Created from images shared within the Pip-Boy build conversation.

This archive preserves the visual build history, including:
- early Raspberry Pi / Pygame interface iterations
- STAT / ITEMS / DATA / map / radio development and testing
- Raspberry Pi desktop, terminal and troubleshooting stages relevant to the build
- touchscreen and physical screen integration
- 3D-printed enclosure and loose components
- Raspberry Pi / board installation and internal structure
- speaker, power, ports and wiring work
- wrist casing, magnets and fitment
- later assembled casing
- hinge positioning / latch preparation

Original image files are preserved rather than recompressed.
