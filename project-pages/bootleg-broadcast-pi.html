Pygame applications / Raspberry Pi

Bootleg Broadcast Pi TV

The browser broadcast has a second life as a small physical TV. This native Python and Pygame version puts the channel selector, schedule and controls on a Raspberry Pi screen while mpv handles the actual video.

Working proof of conceptv0.4.3Python + Pygamempv

Open the web broadcast ↗

From website to screen

Ten channels, one small television

The original Bootleg Broadcast runs in a browser with a CRT frame, a remote and scheduled media from the Internet Archive. I wanted to see whether the same experience could live in a dedicated device that you can turn on and tune like a television.

The Pi version pulls the channel schedule and break information from the web project, then presents it in a full-screen Pygame interface. The current build includes all ten channel logos and local ident clips. If a network break cannot be fetched, a local station ident can fill that slot.

Under the hood

Native controls and video

Pygame draws the interface and remote controls. mpv renders video into a dedicated X11 child surface inside the player area, so the UI does not paint over playback. The packaged idents are smaller H.264 files suited to the current Raspberry Pi display.

Current state

A real device prototype

The interface, channel data, controls, logos and video now work on the Pi. Playback has been improved by reducing unnecessary screen redraws and buffering remote streams. Hardware limits still affect smoothness, so it is a proof of concept being refined on the device.

How this relates to the website
